How Tax Evidence Pack handles data

Desktop vault

The desktop app stores your encrypted vault, original files, and document metadata on your device. It does not upload evidence, use analytics, or include advertising trackers.

Website storage

The sample demo uses a browser key starting with demo:. It does not read or write a real binder. If you buy Plus or restore a license, the site stores the license token and a cached verification result in browser storage.

License verification

License verification goes to Sociobot’s billing API only when needed. Sociobot/Dodo is the merchant of record.

Your choices

You can remove a local vault through your operating system and clear browser storage at any time. Deleting a vault cannot be reversed without your own backup.
